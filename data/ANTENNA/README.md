# Antenna Pattern Data

The `antenna_patterns_*` folders are generated caches for phased-array antenna
pattern JSON files. They are owned by `AntennaPatternGenerator` when an INI file
contains an `[ANTENNA PATTERN]` section.

Current scenario folders:

- `antenna_patterns_ship`: used by `Configuration_ship.ini`
- `antenna_patterns_area`: used by `Configuration_area.ini`

Keep each scenario pointed at its own `pattern_folder` when the antenna sweeps
differ. Reusing one folder for different sweeps forces regeneration and can
make tests or concurrent runs interfere with each other.

The generated `array_factor_*.json` files and
`antenna_pattern_metadata.json` files are cache artifacts. They can be deleted
and regenerated by running the corresponding simulation or initialization.
