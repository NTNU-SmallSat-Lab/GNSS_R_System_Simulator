


# <div align="center">GNSS-R System Simulator</div>

Date: 16.05.2025
Version: 00
Authors:	Oliver Hasler
				Corrado Chiatante

This simulator is intended as an early stage preliminary design tool for GNSS-R satellite missions with the aim of ocean surveillance and/or GNSS-RFI.

In the current state it allows the following simulation settings:
- GNSS satellite constellations [GPS, GALILEO, GLONASS, BEIDOU]
- GNSS-R satellite constellations:
	- Orbit(s), 
	- Number of satellites
	- (satellite properties)
	- TBD

These settings allow to calculate the specular reflections on earth (earth can be specified as spherical or elliptical)

 ### Example configuration file (configuration.ini)
[SIMULATION SETTINGS]
startTime                  = 02.04.2025 12:00:00
stepSize                    = 30
simulationDuration = 10

[ORBITS]
orbit1 = [99.1, 0.00001, 0,    0, 0, 7300e3]
orbit2 = [99.1, 0.00001, 90.0, 0, 0, 7300e3]

[BOUNDING BOX]
min_longitude = -17
max_longitude = 30
min_latitude = 56
max_latitude = 80

[GNSS CONSTELATIONS]
gnss_const_names = [GPS, GALILEO]
gnss_tle_files = [GPS_operational.tle, GALILEO.tle]

[COVERAGE]
shapefile_path = data\autogenerated_ship_trajectory\DarkShip_001_trajectory.shp
