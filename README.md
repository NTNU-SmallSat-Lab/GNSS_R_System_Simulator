


# <div align="center">GNSS-R System Simulator</div>

Date: 16.05.2025
Version: 00
Authors:	Oliver Hasler, Corrado Chiatante

This GNSS-R simulator is intended as an early-stage, preliminary design tool for GNSS-R satellite missions with the aim of ocean surveillance and/or GNSS-RFI.
At the current state, this simulator allowes area coverage analysis and an a analysis of detection probability for moving or stationary targets on the ocean surface (see: [Workflow]). <br>

A area coverage analysis allows to estimate how many times a certain user defined grid-cell (e.g. 30x30 km) in a user defined area (e.g. Norwegian sea) is covered by a specular-reflection within a certain time horizon (e.g. 3h) (see [Figure 1](#fig-coverage)). The following is needed to do this analysis: <br>

- satellite constellation
- area of interest (as shapefile)
- size of a grid-cell
- simulation duration
- antenna cutoff-angle

<a name="fig-coverage"></a>
![Example output of coverage analysis](MISC/Coverage_grid_GPS_GALIEO.png)
*Figure 1: Example output of coverage analysis showing reflection coverage over the norwegian coast. Grid cells have a edge-length of 30 km, the simulation duration is 3h and the GPS and GALILEO GNSS constellations are considered*

The similator can also be used to estimate if a moving or stationary target (see see [Figure 2](#fig-mg_tgt)) could be detected. The simulator provieds an estimate how many times such a target could be detected given the following:

- Vehicle path, speed and start time
- satellite constellation
- GNSS-R antenna (incl. cutoff angle)

## Workflow

The simulator allows currently two kind of analysis:

 1. Coverage analysis: This allows to analyse how much coverage a certain predefined area is getting.
 - The area of interest (bounding box) is devided into predefined segments with equal size (area)
 - Over a certain time (userdefined) the coverage of this segments is determined
 - A segment is considered "covered" when a reflection is occuring within a segment in the defined timespan

 2. Detection of moving targets:
 - This analysis allows to determine the possible intersection points of a moving target.
 - A start and endposition are defined 
 
 ### main_simulation_areaCoverage.py

This is used to analyse the coverage of a certain area with a given satellite constellation.

Example initialization file: <br>
[SIMULATION SETTINGS]  <br>
startTime = 02.04.2025 12:00:00 <br>
stepSize = 30 <br>
simulationDuration = 4 <br>
 <br>
[COVERAGE] <br>
shapefile_path = data\International_hydrographic_organization\iho_norwegian_coast.shp <br>
grid_size_meters = 30_000 <br>
 <br>
[ORBITS] <br>
orbit1 = [99.1, 0.00001, 0,    0, 0, 7300e3] <br>
orbit2 = [99.1, 0.00001, 90.0, 0, 0, 7300e3] <br>
 <br>
[BOUNDING BOX] <br>
min_longitude = -17 <br>
max_longitude = 30 <br>
min_latitude = 56 <br>
max_latitude = 80 <br>
 <br>
[GNSS CONSTELATIONS] <br>
gnss_const_names = [GPS, GALILEO] <br>
gnss_tle_files = [GPS_operational.tle, GALILEO.tle] <br>
