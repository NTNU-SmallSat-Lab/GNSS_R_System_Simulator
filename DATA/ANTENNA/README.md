# Antenna Pattern Data

The `antenna_patterns/` folder is the generated cache for phased-array antenna
pattern JSON files. It is owned by `AntennaPatternGenerator` when an INI file
contains an `[ANTENNA PATTERN]` section. Both `Configuration_ship.ini` and
`Configuration_area.ini` currently point at this single folder.

Sharing one folder works as long as both INIs configure the same
`[ANTENNA PATTERN]` (elements, spacings, freqs, steering sweep, resolutions);
the generator's metadata signature then cache-hits across scenarios. If you
need different antennas per scenario, point each INI at its own
`pattern_folder` — otherwise the second sim will detect a signature mismatch
and force a full regenerate every time you switch.

The generated `array_factor_*.json` files and `antenna_pattern_metadata.json`
are cache artifacts. They can be deleted and regenerated by running the
corresponding simulation or initialization.
