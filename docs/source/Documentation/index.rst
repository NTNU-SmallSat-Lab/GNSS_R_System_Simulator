Module Documentation
=====================

The pages below mirror the ``SRC/`` source layout. Cross-cutting helpers live under
``SRC/functions`` and the simulation objects (satellites, reflections, targets, detectors) live under
``SRC/object_definitions``. The INI and YAML parser in ``SRC/__init__.py`` has its own page; the
Monte Carlo harness ``SRC/run_monte_carlo.py`` is documented in :doc:`../monte_carlo`.
