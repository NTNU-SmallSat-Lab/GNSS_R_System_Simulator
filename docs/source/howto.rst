How-to guides
=============

Short recipes for the most common changes to a scenario. Every change is made in ``Configuration.ini``
(the scenario) or ``simulator_settings.yaml`` (engine settings); no code changes are needed. The full key
reference is :doc:`Documentation/configuration`.

Choose the analysis and the reflection mode
-------------------------------------------

The **analysis** is chosen by the entry script: ``SRC/main_simulation_areaCoverage.py`` for area
coverage, ``SRC/main_simulation_movingTarget.py`` for a moving target. The **reflection mode** is one
key, used by both:

.. code-block:: ini

   [REFLECTION]
   reflection_type = "specular"      ; or "backscatter"

Backscatter needs ``[REFLECTION].max_incidence_angle_deg``, and backscatter area coverage also needs
``[COVERAGE].max_bistatic_bksc_angle_deg`` (the swath half-angle). :doc:`modes/index` explains the two
modes.

Change the coverage region or grid
----------------------------------

Point ``shapefile_path`` to any polygon shapefile in geographic longitude/latitude (EPSG:4326) and set
the cell size in metres:

.. code-block:: ini

   [COVERAGE]
   shapefile_path = DATA/my_region/my_region.shp
   grid_size_meters = 50_000

The grid is cached next to the shapefile as ``<name>_gridded_m.shp`` and reused while that file exists.
**After changing** ``grid_size_meters``, **delete the** ``<name>_gridded_m.*`` **files**; otherwise the
old grid is used. Smaller cells give finer maps and longer runs.

Define the receiver constellation
---------------------------------

Each LEO receiver is one ``orbitN`` key with the classical elements
``[inclination_deg, eccentricity, raan_deg, arg_periapsis_deg, true_anomaly_deg, semi_major_axis_m]``,
all at ``[SIMULATION SETTINGS].startTime``:

.. code-block:: ini

   [ORBITS]
   orbit1 = [97.5, 0.0001, 0.0, 0.0, 0.0, 6878e3]     ; 500 km sun-synchronous, plane 1
   orbit2 = [97.5, 0.0001, 0.0, 0.0, 180.0, 6878e3]   ; same plane, opposite side
   orbit3 = [97.5, 0.0001, 90.0, 0.0, 0.0, 6878e3]    ; second plane, 90 deg RAAN offset

Keys are read as ``orbit1``, ``orbit2``, ... until the first missing number, so the numbering must be
continuous. The perigee radius :math:`a(1-e)` must exceed the Earth's equatorial radius. A TLE is
generated for every receiver under ``DATA/TLE_EPHEMIRIS/autogenerated/`` (see
:doc:`Documentation/object_definitions/satellites`).

Select GNSS constellations and signals
--------------------------------------

``gnss_tle_files`` loads constellations; ``bands`` selects the signals. Band names are constellation
specific (``L1``/``L2``/``L5`` GPS, ``E1``/``E5a``/``E5b``/``E6`` Galileo, ``G1``/``G2``/``G3`` GLONASS,
``B1I``/``B1C``/``B2a``/``B2b``/``B2I``/``B3I`` BeiDou), so a band only takes effect when its
constellation is loaded:

.. code-block:: ini

   [GNSS CONSTELLATIONS]
   gnss_tle_files = [GPS_operational.tle, GALILEO.tle, BEIDOU.tle]

   [ANTENNA]
   bands = ["L1", "E1", "B1C"]

Unknown bands, bands without a transmit EIRP, and bands of a constellation that is not loaded are
dropped with a warning. In area coverage the band only selects which constellations take part (coverage
is geometric); in moving-target runs every band is evaluated separately.

Update the GNSS orbits (TLEs)
-----------------------------

Orbit propagation (SGP4) loses accuracy with distance from the TLE epoch. The bundled TLE files carry the
epochs of the published study (GPS May 2025, the other constellations October 2024). For a new study,
download current element sets from `CelesTrak <https://celestrak.org/>`_ into ``DATA/TLE_EPHEMIRIS/``,
for example:

- GPS: ``https://celestrak.org/NORAD/elements/gp.php?GROUP=gps-ops&FORMAT=tle``
- Galileo: ``https://celestrak.org/NORAD/elements/gp.php?GROUP=galileo&FORMAT=tle``
- GLONASS: ``https://celestrak.org/NORAD/elements/gp.php?GROUP=glo-ops&FORMAT=tle``
- BeiDou: ``https://celestrak.org/NORAD/elements/gp.php?GROUP=beidou&FORMAT=tle``

Each file name must contain ``GPS``, ``GALILEO``, ``GLONASS`` or ``BEIDOU``, because the constellation is
matched from the name. Then set ``startTime`` close to the new epochs:

.. code-block:: ini

   [SIMULATION SETTINGS]
   startTime = 15.10.2026 00:00:00     ; dd.MM.YYYY HH:mm:ss, UTC
   simulationDuration = 24             ; area coverage only, whole hours

Set up the ship
---------------

The moving target sails from ``start_pos`` to ``end_pos`` at ``speed``; the route is planned around land
over the Natural Earth ocean mesh, so both ends must lie on water. The travel time sets the simulated
window, so a longer route means a longer run:

.. code-block:: ini

   [MOVING TARGET]
   speed = 15                     ; knots
   start_pos = [56.0, 3.0]        ; [latitude, longitude] -- latitude first
   end_pos = [61.0, 3.0]

   [SHIP]
   length_m = 300.0               ; above-waterline dimensions
   beam_m = 50.0
   freeboard_m = 20.0

A route that the planner has seen before is loaded from ``DATA/autogenerated_ship_trajectory/``
instead of being planned again (see :doc:`Documentation/object_definitions/ship_trajectory`).

Set the sea state
-----------------

All six ``[OCEAN]`` keys are required. Wind speed drives the surface slopes and the Bragg spectrum; the
significant wave height sets the roughness that suppresses the coherent reflection:

.. code-block:: ini

   [OCEAN]
   ocean_wave_height_m = 2.5       ; significant wave height H_s
   ocean_wind_speed_m_s = 10.0
   ocean_wind_direction_deg = 270.0 ; direction the wind blows FROM, clockwise from north
   ocean_sea_temperature_c = 8.0
   ocean_salinity_psu = 35.0
   ocean_inverse_wave_age = 0.84   ; 0.84 = fully developed sea

The model behind these inputs is described in :doc:`Documentation/object_definitions/ocean_target`.

Change the receiver antenna
---------------------------

The phased array is defined by its element grid and spacing, and the beam can be steered within the two
extents:

.. code-block:: ini

   [ANTENNA PATTERN]
   elements_along_x = 4
   elements_along_y = 4
   d_x = 0.0951                   ; m, half a wavelength at GPS L1
   d_y = 0.0951
   along_track_steering = [-30, 30]
   across_track_steering = [-30, 30]

   [ANTENNA]
   footprint_db = -3.0            ; footprint contour, below the 0 dB peak

The steering extents must satisfy :math:`\sin^2\theta_\mathrm{across}+\sin^2\theta_\mathrm{along}\le 1`
at their maxima. The patterns are regenerated automatically after a change. The angular resolution and
the number of steering steps are engine settings in ``simulator_settings.yaml`` (the step counts must be
odd so that boresight is included). See :doc:`Documentation/object_definitions/antenna`.

Tune the detection link budget
------------------------------

The receiver processing enters the moving-target metrics through the detection-equivalent noise
:math:`N_\mathrm{eff} = k\,T_\mathrm{sys}/(T_\mathrm{coh}\sqrt{M})`:

.. code-block:: ini

   [LINK BUDGET]
   system_noise_temperature_k = 290.0
   coherent_integration_time_s = 0.001   ; T_coh; also sets the Doppler width of the clutter cell
   num_incoherent_looks = 1000           ; M
   detection_sinr_threshold_db = 0.0
   delay_doppler_cell_enabled = true     ; ocean clutter from one delay-Doppler cell
   ocean_patch_integration_enabled = false

``delay_doppler_cell_enabled`` and ``ocean_patch_integration_enabled`` choose the ocean-clutter area and
cannot both be ``true``. Area coverage ignores the noise, detection and clutter-cell keys. See
:doc:`Documentation/functions/link_budget` and :doc:`Documentation/functions/delay_doppler`.

Make an animation
-----------------

.. code-block:: ini

   [PLOT]
   create_animation = True
   animation_filename = Reflection_animation.gif
   animation_fps = 2

The GIF is written to ``OUTPUT/`` with the reflection mode added to its name. It has one frame per
simulation step with a reflection in view, so it grows with the route length.

Change the time step
--------------------

The propagation step is an engine setting:

.. code-block:: yaml

   simulation:
     step_size_s: 20

A smaller step resolves the reflection tracks more finely and increases the run time in proportion. In
moving-target runs the step is also the time tolerance for matching a reflection to the ship position.
